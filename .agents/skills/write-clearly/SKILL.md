# Write Clearly

Read [references/style-guide.md](references/style-guide.md) completely before drafting or revising
prose.

## Work

1. Identify the audience, requested outcome, and next action.
2. Identify who actually performed each action. Do not preserve the source text's framing when it
   gives agency to an object or hides the actor.
3. Draft in the audience's vocabulary.
4. Apply every relevant rule in the style guide.
5. Read the result aloud mentally. Rewrite anything a colleague would not naturally say.
6. Remove process narration, repetition, and internal terminology that the reader does not need.

## Return

Return the outcome first. State a decision or request plainly. Do not explain the editing process
unless the user asks.
