# Architecture documentation

This directory describes Mandem's system boundaries, architecture rules, integration contract, and
agent-vendor-neutral operating model.

- [Agent vendor neutrality](./agent-vendor-neutrality.md) explains where shared agent guidance
  belongs.
- [Architecture standard v1](./architecture-standard-v1.md) defines the checked module and source
  rules.
- [Consumer integration contract](./consumer-integration-contract.md) defines the U8 consumer
  boundary.
- [Mandem system](./mandem-system.md) describes the CLI, server, and module boundary.
- [Third-party attribution](./third-party-attribution.md) records external sources and licenses.
