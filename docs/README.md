# Mandem documentation

This directory contains the maintained documentation for Mandem. Each linked directory has its own
index for local documents and child directories.

- [Architecture](./architecture/README.md) describes system and repository design.
- [Development](./development/README.md) describes contributor expectations.
- [Operations](./operations/README.md) records operating evidence and capability baselines.
- [Plans](./plans/README.md) contains the epic plan, issue plans, and plan reviews.
- [Solutions](./solutions/README.md) captures reusable engineering guidance.
- [Sources](./sources/README.md) records the pinned external source material used by Mandem.
